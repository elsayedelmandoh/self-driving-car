## Overview

This project features a small car controlled via a Wi-Fi application using a NodeMCU ESP8266. The system integrates an L298N Motor Driver, gear motors, robot wheels, a battery holder, jumper wires, and Li-ion batteries for a fully functional remote-controlled vehicle.

## Components Used

- **NodeMCU ESP8266**: Microcontroller with built-in Wi-Fi capability.
- **L298N Motor Driver**: Controls the gear motors.
- **Gear Motors**: Drive the robot wheels.
- **Robot Wheels**: Attached to the car for movement.
- **Battery Holder**: Holds the Li-ion batteries.
- **Jumper Wires**: For electrical connections.
- **Li-ion Batteries**: Power source for the system.

## Features

- **Wi-Fi Control**: Operate the car remotely via a dedicated application.
- **Directional Movement**: Move forward, backward, left, and right.

## Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/yourusername/wi-fi-controlled-car.git
   ```

2. **Setup the Hardware**

- Connect the NodeMCU ESP8266 to the L298N Motor Driver.
- Attach the gear motors and robot wheels.
- Install the Li-ion batteries in the battery holder.

3. **Upload Code to NodeMCU**

- Open the Arduino IDE and load the provided code.
- Select the correct board and port.
- Upload the code to the NodeMCU.

4. **Configure Wi-Fi Application**

- Set up the Wi-Fi application as per the instructions in the code comments.
